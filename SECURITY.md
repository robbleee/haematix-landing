# Security Policy

Do not report vulnerabilities in a public issue and do not attach patient data,
credentials, tokens, or production logs to an issue or pull request.

Use GitHub's private vulnerability-reporting flow when it is available.
Otherwise, contact the HAEMIO LTD team through an established private channel.
Include the affected repository and commit, impact, safe reproduction steps,
and suggested remediation. Use synthetic data in every example.

The supported version is the current default branch. If a secret may have been
exposed, rotate it immediately; removing it from Git history is not sufficient.
