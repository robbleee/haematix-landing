# Cookie Notice

**Last updated:** 7 July 2026  
**Version:** 1.0

This notice explains how Haemio Ltd uses cookies, local storage, and similar technologies on the Haem.io website.

## 1. What We Use

The website currently uses:

- essential local storage to remember your cookie banner choice;
- Vercel Analytics to understand website usage and performance after you accept analytics;
- technical cookies or storage needed for routing, security, and normal website operation.

We do not currently use Google Analytics, Facebook/Meta pixel, Hotjar, or PostHog on the landing site.

## 2. Essential Storage

We use browser storage to remember whether you accepted or declined the cookie banner. This helps avoid showing the banner repeatedly.

| Name | Purpose | Type |
| --- | --- | --- |
| `cookie-consent` | Stores cookie banner preference | local storage |

## 3. Analytics

We use Vercel Analytics to understand broad usage patterns and site performance after you accept analytics. This helps us improve content, pages, and reliability.

Analytics data may include technical information such as page URL, referrer, device/browser characteristics, and approximate location inferred from network information.

If you decline, the site stores that preference and does not load the Vercel Analytics component in the browser.

## 4. Managing Preferences

You can clear local storage and cookies through your browser settings. If you clear browser storage, the cookie banner may appear again.

## 5. Changes

If we add new analytics, advertising, or tracking tools, we will update this notice and, where required, request consent before using them.
